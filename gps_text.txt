10. GPS Tracking

ஒவ்வொரு 5–10 seconds-க்கும் GPS point capture செய்யலாம்.

Example:

10:00:05 → 12.9720,77.5950

10:00:10 → 12.9725,77.5956

10:00:15 → 12.9731,77.5961

ஆனால் 5 seconds என்பது fixed requirement இல்லை.

Vehicle speed, battery usage, OS restrictions ஆகியவற்றைப் பொறுத்து interval dynamically adjust செய்யலாம்.

13. GPS Quality Check

இது மிகவும் முக்கியமானது.

சில நேரங்களில் GPS:

Actual:

12.9716, 77.5946

GPS:

13.0216, 77.6946

என்று திடீரென்று jump ஆகலாம்.

அப்படி இருந்தால் அதை distance calculation-ல் பயன்படுத்தக்கூடாது.

14. GPS Filtering

ஒவ்வொரு point-ஐ validate செய்ய வேண்டும்.

Check 1 — Accuracy

Example:

accuracy <= 50 meters

என்றால் accept.

அதற்கு மேல் இருந்தால்:

REJECT / LOW CONFIDENCE

என்று mark செய்யலாம்.

15. Check 2 — Impossible Jump

Example:

Previous point

12.9716,77.5946

New point

13.0716,77.6946

இரண்டு points-க்கு இடையில் 5 seconds தான் இருந்தால், vehicle அந்த distance-ஐ realistic-ஆ travel செய்திருக்க முடியுமா என்று check செய்ய வேண்டும்.

Formula:

speed = distance / time

Example:

distance = 2 km

time = 5 sec

இது vehicle-க்கு impossible speed என்றால்:

INVALID GPS POINT

16. Check 3 — GPS Jump Detection

P1 ─── P2 ─── P3

Normal:

P1 → P2 → P3

Bad GPS:

P1 → P2 → X → P3

          ↑

       huge jump

X reject செய்ய வேண்டும்.

17. Distance Calculation

Basic GPS distance:

P1 → P2

P2 → P3

P3 → P4

...

ஒவ்வொரு valid point-க்கும் distance calculate செய்ய வேண்டும்.

Distance =

D(P1,P2)

+

D(P2,P3)

+

D(P3,P4)

...

இதற்கு Haversine formula பயன்படுத்தலாம்.

ஆனால் இது straight-line distance between GPS points.

Road distance வேறாக இருக்கலாம்.
